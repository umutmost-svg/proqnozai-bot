# Модель для сборных (`national-1`)

Владелец, 16.11.2026: модель для матчей сборных («вариант 3»).

## Почему отдельная модель

Модель `goals-1` строится по одному турниру: прошлый сезон плюс текущий. В турнирах сборных у каждой команды
всего 6–10 матчей. Пример: Германия — Нидерланды, Лига наций, 16.11.2026. Модель видела только эту Лигу наций
и отдала перевес Нидерландам, xG 1.02 против 1.27. Модель на общей истории сборных даёт 1.92 против 1.45,
вероятности 48 / 24 / 28.

## Модель

Математика та же, что у `goals-1`: модель Пуассона с поправкой Диксона — Коулза, затуханием по времени и
приором (`forecast/model.py`). Отличается только то, на чём она учится и с какими параметрами.

- **Данные.** Все турниры сборных из `football_data.NATIONAL_CODES` сразу: WC, EC, ECQ, UNL, QUFA, QCBL, QCAF,
  QAFC, QCCF, CA, AC, ACQ. Олимпиада и женские турниры не входят.
- **Окно.** Последние 3 года (`NATIONAL_WINDOW_DAYS`). Разделения на сезоны и правила для новичков нет.
- **Параметры.** Полупериод затухания 730 дней, приор 2 матча (`version.NATIONAL_*`).
- **Нейтральное поле не учитывается.** Вариант с нейтральным полем для финальных турниров на проверке не выиграл.
- **Ставки не рекомендуются.** Правила выбора ставки на сборных не проверялись, поэтому всегда
  `unvalidated_competition`: вероятности показываются, но прогноз помечен как ограниченный (`limited`)
  и не входит в проспективную проверку.
- **Пометка в истории прогнозов.** Прогноз хранит `pool: "national-1"`, а его параметры записываются как
  `<digest>+national-1`.

## Проверка (16.11.2026, офлайн)

Данные: football-data, около 1900 матчей сборных с 2023 года. Более старые сезоны API не отдаёт: WC 2022 — 403,
остальные — 404. Протокол тот же, что у `goals-1`: прогноз в 00:00 UTC дня матча, только по матчам, сыгранным
не меньше чем за 24 часа до этого.

- **Подбор параметров** по матчам 2025 года (455 матчей).
  - Сетка: полупериод затухания 180 / 365 / 730 дней; приор 2 / 5 / 10 матчей; окно 3 / 5 лет;
    нейтральное поле для финальных турниров — да или нет.
- **Проверка** на матчах 2026 года (343 матча), не участвовавших в подборе. В таблице log loss исхода 1X2:

| | national-1 | текущая (по турниру) | средние лиги (B1) |
|---|---|---|---|
| Все матчи 2026 | **0.943** | 1.050 | 1.069 |
| UNL + QUFA (150) | **0.908** | 1.041 | 1.084 |
| WC 2026 (104) | **1.004** | 1.079 | 1.076 |

- **Значимость.** Парный блочный бутстрэп (блоки по 4 недели), разница с текущей моделью: −0.107,
  95% ДИ [−0.136; −0.041]. Для одного ЧМ‑2026 преимущество не значимо: ДИ задевает ноль.
- **Фаворит модели побеждает** в 52.5% матчей против 46.6% у текущей модели.
- **Охват.** Текущая модель могла дать прогноз только на 90 из 343 матчей. `national-1` даёт прогноз на 337.

## Данные в продукте

- **Сборка истории.** Общая история (`ModelHistory.pool`) собирается только из кэша и никогда не делает запросов
  к провайдеру. Для каждого обслуживаемого турнира сборных в неё входят:
  - текущий календарь;
  - список сезонов (`football:seasons:<code>`, раз в сутки);
  - прошлые сезоны, которые заходят в окно.
- **Подгрузка.** Всё это подгружает фоновый прогрев поиска (`_warm_national`): тот же слот и низкий приоритет,
  примерно 25 запросов в сутки.
- **Пока история не собрана**, работает прежняя модель по одному турниру. Сюда относятся:
  - первые минуты после рестарта;
  - временный сбой загрузки любого сезона.

  Сезон, которого нет у источника (404), пробелом не считается.
- **Стоимость запросов пользователя не меняется:** `history_cost` и `analysis_cost` прежние.

## Ограничения

- **Букмекерские линии.** На истории сравнить с ними нельзя: старых коэффициентов нет.
- **Межконтинентальные матчи.** Сила конфедераций друг относительно друга видна почти только по ЧМ‑2026.
  Для таких матчей прогноз грубее, но и их ставки не рекомендуются.
- **Товарищеские матчи** в данных провайдера отсутствуют.
