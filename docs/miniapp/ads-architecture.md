# Рекламные кампании ProqnozAI — архитектура, сроки, порядок

Статус: проект (2026-11-12), ветка `feat/ads`. Production не меняется; включение — флагами и только по
отдельному разрешению владельца. Основа — утверждённая архитектура админки A2 (`admin-dashboard.md`) и пилот
CRM v2 (`feat/admin-pilot`: роли, журнал действий, сегменты, теги, MB ID).

## 1. Принципы (не обсуждаются в коде)

1. **Реклама не меняет факты.** Исход и коэффициент в рекламной карточке — только из прогноза модели и
   ленты коэффициентов (как сейчас в «Рекомендуемой ставке»); редактор управляет текстами, CTA, ссылкой и
   аудиторией, но не числами. В схеме данных полей «коэффициент»/«исход» у кампании нет.
2. **Аудитория считается на сервере** по проверенной сессии Telegram; клиент получает только итоговое
   предложение для себя. Ответы `Cache-Control: private, no-store`, ключа кеша у Cloudflare нет.
3. **По умолчанию — отказ.** Нет кампании, нет разрешения GEO, неизвестная страна (если кампания её не
   разрешила явно), нет подтверждения 18+ там, где оно требуется, выключен флаг — обычная рекомендация без CTA.
4. **Не используем для воздействия:** проигрыши, признаки зависимости, чувствительные характеристики, язык
   Telegram как страну. Сегменты активности — только по нейтральным событиям приложения.
5. **Бот и его база не участвуют.** Всё — в Mini App и админке (A2).

## 2. Где что живёт (A2)

| Хранилище | Кто пишет | Что |
|---|---|---|
| `admin.db` (admin-контейнер) | admin | кампании, варианты, таргетинг, расписание, эксперименты, группы, журнал действий (`admin_events`), права |
| `ads-policy.json` (общий том `/data`, атомарная запись, версия + SHA-256) | admin публикует | опубликованный снимок активных кампаний: тексты, ссылки, таргетинг, варианты, веса, окна дат. Mini App перечитывает по изменению версии (≤ 30 с) — **без деплоя** |
| `miniapp.telemetry.db` (`/data`) | Mini App | события: визиты, запросы прогнозов, купоны, показы, клики; дневные агрегаты активности по пользователю; неавторитетна |
| `miniapp.db` | Mini App | пользователи (дата регистрации, последний вход), подтверждение 18+ (новая колонка, аддитивно) |

Admin читает `miniapp.db` и `telemetry.db` только на чтение (`mode=ro`) для сегментов, предпросмотра и аналитики.

## 3. Модель данных (admin.db, миграции аддитивные `CREATE TABLE IF NOT EXISTS`)

- `ad_campaigns(id, internal_name, status[draft|scheduled|active|paused|ended|archived], priority_tier[individual|segment|general],
  priority INT, lang_in JSON, starts_at, ends_at, partner_id, disclosure JSON, targeting JSON, experiment_id,
  created_by, created_at, updated_at, published_version)`
- `ad_variants(id, campaign_id, key[A|B|C], weight_pct, headline, body, extra, cta_text, url)` — тексты и ссылка на
  вариант; кампания без A/B = один вариант A/100 %.
- `ad_partners(id, name, url_hosts JSON, allowed_countries JSON, age_min, disclosure_template JSON, active)` —
  разрешённые домены ссылок и юрисдикции **на уровне партнёра** (кампания не может их расширить).
- `ad_experiments(id, campaign_id, salt, control_pct, started_at, stopped_at)`.
- `ad_groups(id, name)`, `ad_group_members(group_id, user_id)` — группы (поверх CRM-тегов пилота).
- Все изменения — через `admin_events` в той же транзакции (до/после — белый список полей).

`disclosure` (маркировка): «Реклама» (всегда), рекламодатель (название — показывается, только если это требует
юрисдикция), идентификатор рекламы (например erid для РФ), возрастная метка (18+) — поля есть, заполнение и
правила по странам задаёт владелец (раздел 9).

## 4. Таргетинг и приоритет

Условие — дерево `{all: [...]} | {any: [...]} | {not: …}` из листьев:
`geo_in[ISO2…]`, `geo_unknown`, `user_in[Telegram id…]`, `mb_verified`, `mb_id_in[…]`, `group_in[…]`,
`segment(name, params)`, `lang_in`. Глубина ≤ 4, листьев ≤ 30 (валидация в админке и при чтении снимка).

Сегменты активности (параметры настраиваются): новые (регистрация ≤ N дней), активные (визиты за 7/14/30 дней ≥ N),
очень активные, неактивные (последний вход ≥ N дней назад), вернувшиеся (перерыв ≥ N дней, затем визит за M дней);
числа запросов прогнозов, созданных купонов, переходов по предложениям за период. Источник — `telemetry.db`.

**GEO**: `CF-IPCountry` от Cloudflare. Доверяем ему только для запросов с верным `X-Edge-Auth`, то есть
пришедших через Cloudflare, а без секрета приложение и так отвечает 403. Значения `XX`/`T1` и отсутствие
заголовка означают «неизвестно». Страна определяется на каждый запрос и не сохраняется в профиль.

**Выбор кампании (детерминированно):** отбираем кампании, у которых сейчас окно дат и статус active,
совпадает язык, условие истинно, GEO разрешено партнёром и кампанией, выполнено требование 18+.
Порядок: уровень (individual > segment > general), затем `priority` по убыванию, затем более поздний
`starts_at`, затем меньший `id`. Берётся первая. Все ветки покрыты таблично-заданными тестами.

## 5. A/B

Вариант = `hash(experiment.salt, user_id) mod 10000` → интервалы по весам (сумма 100 %, контрольная группа —
отдельный интервал, без рекламы). Стабильно для пользователя на всё время эксперимента; смена весов меняет
распределение только у новых интервалов (соль фиксирована). Сравнение: показы, уникальные, клики, CTR, доверительный
интервал (Вильсон) по каждому варианту.

## 6. API Mini App (сессия + CSRF для записи; флаг `MINIAPP_ADS_ENABLED`, по умолчанию off)

- `GET /api/ads/offer?placement=quick_pick|ai_pick&event_id=…` → `{offer: null}` или
  `{offer: {id, variant, headline, body, extra, cta, disclosure, impressionToken}}`. Ссылки в ответе нет.
- `POST /api/ads/impression {impressionToken}` — один показ на (пользователь, кампания, вариант, событие, день).
- `POST /api/ads/click {impressionToken}` → `{url}`: ссылка из **текущего** снимка, проверенная (https, хост из
  разрешённых партнёра, без user info). Клиент открывает её через `Telegram.WebApp.openLink`; своего
  `/redirect?to=` нет — открытый редирект невозможен. Клики дедуплицируются (окно 10 с на токен).
- Токен показа — HMAC(user, campaign, variant, event, day): чужое предложение по нему не получить, подделка → 403.

## 7. Mini App UI

Карточка внутри «Рекомендуемой ставки» (быстрый прогноз; AI-разбор — когда он включится): исход и коэффициент
крупно (из модели и ленты), тексты кампании, заметная CTA, строка «Реклама партнёра» + поля маркировки.
Тексты — только как текст (React, без HTML). Без предложения — прежняя карточка без CTA. 320–430 px, iOS/Android/
Desktop, тёмная тема.

## 8. Админка

Разделы: кампании (список, фильтры, статусы), редактор (черновик → предпросмотр → публикация), аудитория
(конструктор условий с подсчётом охвата), партнёры и домены, A/B, аналитика (показы, охват, клики, CTR по дням/
GEO/сегментам/вариантам; фильтры; CSV), журнал изменений. Права: owner — всё; admin — кампании и публикация;
analyst — только чтение и аналитика. Пауза/архив/копия/расписание — действия с записью в журнал.

## 9. Решения владельца (до включения для реальных пользователей)

1. Список юрисдикций, где показ разрешён для каждого партнёра (по умолчанию — нигде); поведение для неизвестной страны.
2. Возраст: подтверждение 18+ в Mini App (однократно, хранится у пользователя) — где обязательно.
3. Маркировка по странам: что показывать (рекламодатель, erid, 18+).
4. Источник конверсий: без постбэков партнёра конверсии не считаются (только клики).
5. Сроки хранения: события — 90 дней, агрегаты — 13 месяцев (предложение).

## 10. Сроки и порядок (рабочие дни)

| Этап | Содержание | Срок |
|---|---|---|
| 0 | Ветка: слить пилот админки (`feat/admin-pilot`) с текущим релизом | 0,5 |
| 1 | Модель данных, публикация снимка, движок таргетинга, приоритет, A/B — с тестами | 2 |
| 2 | События и сегменты активности (`telemetry.db`), сроки хранения | 1 |
| 3 | API Mini App (offer/impression/click), безопасность, тесты на чужие предложения | 1 |
| 4 | Карточка в Mini App за флагом, E2E на 320–430 px | 1 |
| 5 | Админка: кампании, редактор, аудитория, партнёры, предпросмотр, A/B, журнал, права | 3 |
| 6 | Аналитика и экспорт | 1,5 |
| 7 | Полный E2E, Codex до APPROVE, документация | 1,5 |
| 8 | Внедрение: админка на сервер (Dokploy, Access), флаг off → только владелец → % аудитории | 0,5 + окна |

Итого ≈ 12 рабочих дней разработки. Коэффициенты MB идут раньше и не ждут модуль: карточке нужны реальные цены.

**Откат:** `MINIAPP_ADS_ENABLED=false` (Redeploy Mini App) или пауза всех кампаний в админке (снимок без
кампаний, вступает за ≤ 30 с); данные `admin.db`/`telemetry.db` не удаляются.
